1. The Global Physical RAM
c


7: char memory[MEMSIZE];
8: int isize = 1024 , dsize = 4096;
memory[MEMSIZE]: The single 8192-byte physical RAM array. All processor cores and all tasks store their code and data inside this single buffer.
isize = 1024: Max instruction size in bytes (2 pages of 512 bytes each).
dsize = 4096: Max data memory size in bytes (8 pages of 512 bytes each).
